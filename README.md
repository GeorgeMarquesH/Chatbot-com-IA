# 💬 ChatBot com IA

## 📌 Descrição
Projeto em Python que cria um chatbot interativo usando **Streamlit** para o frontend e a API da **OpenAI** para gerar respostas inteligentes em tempo real.

---

## 🚀 Etapas principais
1. Criação da interface com Streamlit.
2. Campo de entrada para mensagens do usuário.
3. Exibição das mensagens enviadas e das respostas da IA.
4. Manutenção do histórico de conversa na sessão.
5. Integração com o modelo `gpt-3.5-turbo` da OpenAI.

---

## 🛠️ Tecnologias
- Python  
- Streamlit  
- OpenAI API  

---

## 📊 Resultado
Chatbot funcional com interface simples, capaz de responder às mensagens do usuário em tempo real e manter o histórico da conversa.
